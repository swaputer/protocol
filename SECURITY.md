# Security policy

Swaputer is currently an **unaudited experimental system**. The frozen review baseline is
`swaputer-v1.1-stage7c-rc2` at commit
`afa54c2e02e7e91430b14b6884faff5e3f5867d9`. It is historical review material, not an
audit report, and it does not cover the current v1.2 line. The project does not plan to
commission an independent external audit for the current release. No public-mainnet or
real-value testing is authorized until the Stage 7M gates are complete.

The Stage 7M operating decision provides no dedicated security-reporting channel, response SLA or
funded bug bounty. The disclosure and contact documents below are retained as inactive contingency
templates, not as a managed reporting service. Never test against real users, third-party funds or
public mainnet state.

Scope, severity, proof requirements and safe-harbor draft are documented in:

- [Bug bounty policy](docs/security/BUG-BOUNTY-POLICY.md)
- [Severity matrix](docs/security/SEVERITY-MATRIX.md)
- [Security contact runbook](docs/security/SECURITY-CONTACT-RUNBOOK.md)
- [Unaudited capped-mainnet policy](docs/STAGE7M-UNAUDITED-MAINNET.md)

This is a preparation package, not a live reporting channel or funded bounty.
