# Security contact runbook — inactive contingency template

No dedicated security-reporting inbox, response SLA, on-call owner or funded program is planned
for Stage 7M. The placeholders below are retained only in case the project later changes that
decision; they are not current launch requirements:

- primary security inbox: `SECURITY_CONTACT_TBD`;
- backup contact and on-call owner: `SECURITY_BACKUP_TBD`;
- acknowledgement/update SLAs;
- secure attachment/key exchange method;
- legal and communications contacts;
- real reward budget, if any.

On receipt: assign a private finding ID, acknowledge without judging severity, preserve the original
report, reproduce against the exact tag, restrict access, assess whether an official World should be
deprecated, and agree on embargo. Never request a reporter's private key. Deduplicate by root cause,
record rationale, and keep reporter credit separate from any reward decision.

Escalate suspected Critical/High immediately to the incident process. Since there is no pause or
upgrade authority, focus on stopping official recommendations, evidence capture and replacement
World/migration preparation.
